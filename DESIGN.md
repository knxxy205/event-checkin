# Event Check-in — Design direction

## Identity
Rsvply is an event operations desk for people opening doors, checking names, and keeping a live guest count.

## Personality
Calm under pressure, precise, warm without being decorative. The interface should feel like a well-run venue desk, not a generic SaaS template.

## Palette
- Ink: #171812 — ground and primary text.
- Olive: #363f02 — active navigation, successful check-in, primary action.
- Paper: #f4f3ee — working surface.
- White: #ffffff — panels and readable content surfaces.
- Brown: #957048 — event identity and secondary emphasis.

## Typography
DM Sans for interface copy and IBM Plex Mono for codes, timestamps, labels, and operational metadata. Use mono to signal data, not as decoration.

## Composition
Desktop admin-first: narrow dark navigation rail, a generous event header, four deliberately unequal information layers, and one dominant arrivals table. Mobile moves navigation into a drawer and keeps the scan action visible.

## Motion
Subtle only. Use motion for drawer state and feedback, never for decoration. Respect reduced motion.

## Dials
ENERGY 5 / RHYTHM 5 / MOTION 3

## Purpose notes
- Olive is reserved for active/success/action so status reads without relying on color alone.
- Brown identifies event context and secondary emphasis; it is not a decorative gradient.
- The attendance ring gives a fast proportion read; the legend repeats values for accessibility.
- The spark bars show recent arrival shape only after real check-in data replaces the current demo values.
